# Where in the World Is Cameron SanFrancisco?

A geography detective game inspired by the 1985 classic. Chase F.A.N.G. (the Federation of Art-Nabbing Gangsters) around the world as a detective for G.L.O.B.E. (Gumshoes Looking Over Basically Everything), and finally catch Cameron SanFrancisco himself.

## Play

Open `preview/index.html` in a web browser. Use the arrow keys and Enter (Esc goes back, H goes home, M toggles sound), or click and tap.

## Files

- `preview/index.html`: the game logic and screens
- `preview/clues.js`: geography clues for each city
- `preview/sound.js`: sound effects and music, made with Web Audio
- `preview/art/`: pixel art for landmarks, buildings, portraits and characters

The final target is a handheld Raspberry Pi 3 build.
